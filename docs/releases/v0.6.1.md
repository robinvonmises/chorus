## New
- **@-mentions in groups.** Type `@` in a group chat and pick a member from the list (filters as you type; arrow keys, Enter, Tab and Esc on desktop). Signal, WhatsApp and Telegram receive a real mention that notifies the person. Works for captions, retries and scheduled messages too.
- Incoming mentions from Signal and WhatsApp now show as `@Name` instead of a placeholder or phone number.

## Upgrade
```bash
docker compose pull && docker compose up -d
```
With automatic updates set up, nothing to do.
