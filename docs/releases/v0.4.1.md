## New
- **Forward messages**, also across messengers: long-press a message, choose "Weiterleiten" and pick one or more chats (Signal, WhatsApp, Telegram, e-mail, groups included). Text and attachments (photos, videos, files, voice messages) are sent as a new message in each target chat.

## Upgrade
```bash
docker compose pull && docker compose up -d
```
With automatic updates set up, nothing to do.
