## New
- **E-mail via IMAP/SMTP**: each sender appears as a contact, their subjects as chats. New mail arrives instantly via IMAP IDLE, replies thread correctly (In-Reply-To/References) and land in your Sent folder. Quotes, reply history and signatures are hidden, read state syncs both ways, newsletters can be hidden.
- **Archive and delete e-mail**, per subject or for a whole sender. Archiving moves the mails to the server's archive folder (Gmail: All Mail), deleting moves them to the trash.
- **Translate a single message** from the long-press menu, even without live translation. Only that message's text goes to the AI.

## Improved
- The archive is now a button in the chat list header instead of a row in the list.
- Pull-to-refresh was removed; a manual sync is now a button in the settings ("Jetzt abgleichen").
- App icon references are cache-busted, so browsers and installed web apps pick up the current icon.

## Fixed
- Reactions in Signal groups failed with "Bad Request" (message IDs longer than 100 characters). This also fixes editing, deleting and forwarding in Signal groups.

## Upgrade
```bash
docker compose pull && docker compose up -d
```
With automatic updates set up, nothing to do. Add e-mail like any other account (app password for Gmail/iCloud).
