## New
- **AI reply suggestions**: three short reply chips above the input for the last incoming message (only in chats with AI access enabled, cached per message, always via Haiku).
- **"Transkribieren"** for voice messages, now also without per-chat AI opt-in; WhatsApp transcription fixed.
- **Signal voice notes** are sent as real voice notes (AAC).
- **Live translation**: choose the target language; also works for image and file captions.
- **Photo viewer**: pinch-to-zoom, pan while zoomed, double tap to zoom.
- **Media view per chat**: thumbnails (including video stills), grouped by month, visible close button.
- **Group chats**: sender avatars and airier chat bubbles.
- **Automatic updates** on the server: `bash deploy/auto-update-einrichten.sh` installs a systemd timer that pulls the CI image of each new commit and rolls back if the container doesn't become healthy. Log: `journalctl -u chorus-update`.

## Improved
- Photos in chats load as small previews first (`?thumb=1`), much less data and faster scrolling.
- Smoother UI: fewer re-renders, media reserves its space before loading.
- Signal watchdog: pings every minute, reconnects quietly after 30 minutes of silence, restarts with backoff and no longer falls back to pairing mode on a transient error.
- Cleaner message bubbles without messenger dots.

## Fixed
- The chat no longer jumps to the bottom while scrolling up through older messages.
- The input bar no longer slides out of view on iPhone when the keyboard opens or closes.

## Upgrade
```bash
docker compose pull && docker compose up -d
```
With automatic updates set up, nothing to do.
